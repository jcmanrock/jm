# John C. Mancilla — Portfolio

Personal portfolio site for **John Mancilla**, IT professional and AI Software Development Engineer.

🌐 **Live site:** https://jcmanrock.github.io/jm/

---

## Tech Stack

- **Angular 19** — standalone component, signals, animations
- **SCSS** — custom design system with CSS variables
- **GitHub Actions** — automated deploy to GitHub Pages

## Sections

- **Hero** — typewriter effect with rotating titles, animated photo
- **About** — bio, stats, info grid
- **Skills** — 7 skill groups with tags
- **Experience** — vertical timeline with 6 roles
- **Education & Certifications** — 5 degrees + 22 certifications
- **Contact** — cards + contact form

## Local development

```bash
npm install
npm start
```

Open http://localhost:4200/

## Deploy

Every push to `main` triggers the GitHub Actions workflow and deploys to GitHub Pages automatically.
